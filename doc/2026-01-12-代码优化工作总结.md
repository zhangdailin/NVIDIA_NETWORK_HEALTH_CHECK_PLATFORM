#### 4.3 创建工厂函数

**新增 `createSeverityChecker` 工厂函数**:
```javascript
export const createSeverityChecker = (customLogic = null) => {
  return (row) => {
    // 标准逻辑：检查 Severity 字段
    const severity = String(row.Severity || '').toLowerCase()
    if (severity === 'critical' || severity === 'error') return 'critical'
    if (severity === 'warning' || severity === 'warn') return 'warning'

    // 自定义逻辑
    if (customLogic) {
      const result = customLogic(row)
      if (result) return result
    }

    return 'ok'
  }
}
```

**使用示例**:
```javascript
// 在 BERAnalysis.jsx 中
const getSeverity = createSeverityChecker((row) => {
  const hasSymbolErrors = toNumber(row['Symbol Err']) > 0
  const anomaly = row['IBH Anomaly']
  if (hasSymbolErrors && anomaly) return 'warning'
  return null
})
```

### 5. 修复统计数量不一致问题 (30个组件)

#### 5.1 问题诊断

**根本原因**:
- 顶部指标卡片使用后端 `summary` 的统计数据
- 下方筛选条使用前端 `UnifiedAnalysisPage` 重新计算的统计数据
- 两者的统计逻辑不一致导致数量对不上

**示例**:
```
Cable 跳线标签页：
- 顶部指标卡片：警告 20 (后端统计)
- 完整数据表筛选条：警告 0 (前端统计)
❌ 数量不一致
```

#### 5.2 解决方案

**移除各个分析组件中自定义的 `metricCards`，让 `UnifiedAnalysisPage` 使用统一的前端计算逻辑。**

**修改前**:
```javascript
// CableAnalysis.jsx
const metricCards = [
  {
    key: 'warning',
    label: '警告',
    value: summary?.warning_count ?? 0,  // 使用后端统计
    description: '温度 ≥70°C 或规格不合规',
    icon: AlertTriangle,
  },
]

<UnifiedAnalysisPage
  metricCards={metricCards}  // 传递自定义卡片
  getSeverity={getSeverity}
  ...
/>
```

**修改后**:
```javascript
// CableAnalysis.jsx
// 不再使用自定义 metricCards，让 UnifiedAnalysisPage 使用前端统一计算
// 这样可以确保顶部指标卡片和下方筛选条的数量一致

<UnifiedAnalysisPage
  getSeverity={getSeverity}  // 只传递判断逻辑
  ...
/>
```
